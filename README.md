# SmartCoach — Інтелектуальний Telegram-асистент персонального тренера

Командний проєкт з дисципліни «Командна робота» (група КБ-51, спеціальність 125 «Кібербезпека», ХНУ ім. В. Н. Каразіна).

## Функціональні можливості
- Реєстрація клієнтів у хмарній мікро-CRM на базі Google Sheets (`SmartCoach_DB`).
- Управління розкладом тренувань.
- Запис клієнтів на тренування та підтвердження бронювання.
- Перегляд профілю користувача й інформації про активне бронювання.
- Скасування бронювання з автоматичним звільненням відповідного часового інтервалу.
- ШІ-консультант з фітнесу та спортивного харчування на базі Google Gemini API.

## Встановлення та запуск
1. Клонувати репозиторій.
2. Встановити залежності: `pip install -r requirements.txt`
3. Створити файл `.env` на основі `.env.example` та вказати власні ключі API.
4. Додати файл `credentials.json` з обліковими даними Google Service Account.
5. Запустити бота: `python main.py`
